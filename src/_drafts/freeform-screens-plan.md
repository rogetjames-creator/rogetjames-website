# Freeform + Screens — implementation plan (20 Nov 2026)

Not shipped. Nothing here goes live without James's say-so.

## Ideas
1. Freeform as the umbrella story: Screens (pattern inside a rectangle) → Freeform (artwork sets its own outline) → Wall Art (standalone). Wall Art copy already calls the pieces "freeform designs" (Gallery.jsx:3123) — the language exists, it has no page.
2. /freeform is a curated page that reuses existing photos (Wall Art + /screens/wall-decor + built screens). No new upload category, no prices.
3. "From Q DESIGN to ROGETjames" timeline section on /freeform — only dated, evidenced pieces. No "first"/"pioneer" wording.
4. "Beyond the Rectangle" essay, written once: on-site at /freeform/beyond-the-rectangle, then pitched to publications.
5. Three screen case studies as real pages: photos, location, design, application, material, credits, link to the design.
6. "Freeform" uploader destination so new photos land on the page.
7. Cross-links: /screens ↔ /freeform ↔ /wall-art, plus footer.
8. Monthly neutral AI-assistant check, logged to /stats.

## Steps
Phase 0 — James supplies (only non-technical inputs)
- Earliest Freeform piece + approx year; 5–10 dated old pieces.
- Signature image choice (offer shortlist of 3 from existing photos).
- 3 case-study projects + permission to name client/architect.

Phase 1 — Audit (no site changes)
- /screens: title, h1, crawlable text, alt text, sitemap, internal links, structured data, Search Console queries.
- Neutral AI-prompt baseline (no brand in prompts) + Google results; save log.

Phase 2 — /freeform page (preview → James approves → live)
- Hero = signature image; short definition; three-category explainer; curated grid; timeline; enquiry button.
- All six SEO checks: prerender PAGES, sitemap, linked, index/follow, og:image, readable h1.
- Title "Freeform Laser Cut Metal Wall Art & Screens | ROGETjames" (check against Search Console first).

Phase 3 — Cross-links + uploader destination.
Phase 4 — Case studies (3 pages).
Phase 5 — Essay page; press pitch list + email draft for James to send.
Phase 6 — /screens title/intro test only if Phase 1 shows a gap.
Phase 7 — Week-4 recheck; repeat monthly.
